Peatland Fire Prediction System

Sistem prediksi risiko kebakaran lahan gambut berbasis big data dan machine learning.

🛰️

Data Satelit

Menggunakan data MODIS untuk Land Surface Temperature (LST) dan NDVI, serta CHIRPS untuk curah hujan. Total ~10TB data citra satelit diagregasi menjadi fitur musiman.

⚡

Big Data Pipeline

Google Earth Engine untuk preprocessing citra, PySpark untuk agregasi fitur (~7 juta baris), dan pemisahan data train/test berdasarkan tahun (2015–2021 | 2022–2023).

🤖

Dual XGBoost Model

Model klasifikasi untuk prediksi kemunculan api (binary) dan model regresi untuk prediksi hari sampai curah hujan di bawah 4mm/hari (continuous).

📚 Referensi Ilmiah
  • Field et al. (2016) — Risiko kebakaran meningkat nonlinear saat curah hujan <4mm/hari
  • Nurdiati et al. (2024) — Metode machine learning untuk prediksi kebakaran di Kalimantan
  • Prayoga et al. (2024) — Sistem peringatan dini berbasis threshold untuk Riau
